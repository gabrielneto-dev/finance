# Glossário

- **Pluggy Connect** é o componente usado no fluxo de conexão bancária.
- **Connect Token** é a credencial temporária e restrita que habilita esse fluxo no cliente.
- **Item** representa uma conexão na Pluggy. Uma conexão pode retornar várias contas.
- **Conta** é o recurso ao qual a Pluggy associa as transações.
- **Sincronização** é a atualização dos dados locais com os dados da conexão.
- **Sandbox** é o conjunto de conectores de teste com dados sintéticos.
