# Visão

Finance é um sistema de controle financeiro pessoal integrado à Pluggy. O painel web reúne saldos, extrato, gastos, cartões, faturas e avisos de novas transferências. O Android está previsto para uma etapa posterior. A [especificação do MVP](../../Specs/features/SPEC-0001--mvp-finance/spec.md) descreve o escopo.
