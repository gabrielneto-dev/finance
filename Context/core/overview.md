# Overview

`finance` is a self-hostable personal-finance application. It supports personal use while retaining a multi-user, workspace-scoped domain model for safe sharing and future expansion.

The confirmed initial stack is Next.js full-stack with TypeScript, Prisma ORM, PostgreSQL, and Auth.js. The MVP provides manual financial management for institutions, accounts, cards, transactions, recurring rules, invoices, and a small dashboard. Pluggy is represented as an integration boundary, not an active banking synchronisation in this phase.
