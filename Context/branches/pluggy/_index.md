# Pluggy

Abrange vínculo de instituições, autenticação do provedor, importação e sincronização. A importação do Item autorizado passou com a API real, além da prova com dados sintéticos no sandbox. O processamento local de webhook foi verificado; o callback após consentimento e a entrega HTTPS pelo provedor aguardam homologação.
