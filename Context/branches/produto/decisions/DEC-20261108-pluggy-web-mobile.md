# Pluggy e dois canais de acesso

O solicitante definiu um sistema simples de controle financeiro integrado à Pluggy. A primeira entrega é web e o único cliente móvel previsto é Android, em etapa posterior. O SQLite é o banco escolhido para os dados financeiros. A interface web usa componentes compartilhados com a paleta verde, preto e branco e concentra a rolagem nas listas que precisam dela. A arquitetura e as escolhas de stack estão no [plano](../../../../Specs/features/SPEC-0001--mvp-finance/plan.md). A distribuição do Android permanece em aberto.
