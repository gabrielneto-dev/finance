# Decision

The first delivery includes authentication, workspaces, category seed, institutions, accounts, cards, manual transactions, recurring rules, invoices, and dashboard summaries. Pluggy is modelled only as an integration boundary. Budgets, goals, attachments, WhatsApp, operational AI, advanced reconciliation, and full Pluggy synchronisation are deferred.
